# Wild Wander

A gentle guide to wildlife, wild plants and fungi. Browse by type, habitat, region, diet, season, edible parts and more, and have every story read aloud in a calm voice.

Open `index.html` in a browser. It is a single self-contained file.

Live site (after enabling GitHub Pages): https://thrawn2003.github.io/Wild-Wander/

Photos load from Wikipedia when online; emoji are shown otherwise.
